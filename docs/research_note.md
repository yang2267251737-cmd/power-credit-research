# 电力发行人偿债能力比较：从合并现金流到母公司现金来源

研究日期：2026-10-11。财务快照：2025年末／全年。性质：基于公开年报的初步研究札记；AI已核对，用户独立复核待完成。涉及历史数据，未纳入2026年中期财务、最新授信及融资事件。

## 初步判断

三家公司2025年合并经营现金流均超过购建长期资产支付的现金，但期末货币资金对一年内到期债务的覆盖均较低。需要继续核查资金回流和滚续融资，不能仅凭合并现金流为正就断定发行人母公司短期偿债没有压力。

以当前假设衡量，华电的经营现金流减购建支出对冲击的承受空间较大；华能的合并现金对短债覆盖较高，但购建支出接近经营现金流，且母公司货币资金规模较小；大唐的资产负债率与永续债重分类情景杠杆率较高。不同维度并不指向同一排序，尚不足以形成总体信用排名或个券投资建议。

## 两个必须解释的证据问题

**华电：版本变化不能归为经营变化。** 2024年报披露的2024合并总资产为2,238.75亿元，2025年报的2024比较数为2,654.02亿元；经营现金流由163.36亿元变为194.57亿元。2025年报披露同一控制下企业合并，比较期已重述。新旧债务年末／期初披露相差244.92亿元，现阶段只能登记差额，不能把全额直接归因为某一家并购标的或默认已完成桥接。[旧版报表](https://static.cninfo.com.cn/finalpage/2025-03-28/1222927023.PDF#page=140)、[新版报表](https://static.cninfo.com.cn/finalpage/2026-03-27/1225039299.PDF#page=193)、[合并范围变更](https://static.cninfo.com.cn/finalpage/2026-03-27/1225039299.PDF#page=318)

**华能：债务表有未解释的算术矛盾。** 合并非银行金融机构贷款短长金额138.90 + 98.33 = 237.23亿元，但行合计为236.42亿元；短债分类相加为1,048.69亿元，但列合计为1,047.88亿元。差额均为0.81亿元，超出舍入容差。不能凭算术倒推就把138.90改为138.09。数据库保留原值；覆盖率使用原表合计；两个检查例外登记为同一原文疑点，待可靠披露核实。[原表PDF第108页／印刷第107页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0325/2026032500011_c.pdf#page=108)

## 结论转强或转弱需要什么证据

| 发行人 | 当前研究重点 | 应继续获取的证据 |
|---|---|---|
| 华能 | 母公司资金集中、资本开支压力、原表债务矛盾 | 财务公司存款可用性；资本开支进度；短债分类更正或交叉披露；未使用授信的提款条件 |
| 华电 | 短债占比较高，报告版本变化影响趋势 | 重述及新增合并主体债务桥接；母公司投资现金来源；滚续融资记录与实际可用授信 |
| 大唐 | 合并杠杆和永续债敏感性较高，母公司投资现金重要 | 永续条款及递延利息条件；分红来源与限制；期限结构变化；再融资与担保资料 |

下一阶段统一研究截止日，补入2026年中期财务、评级报告与融资事件，形成“主要偿债来源—压力因素—缓释条件—观察触发因素”的主体一页纸。没有同日可比个券估值前，不从发行人财务指标直接推导信用利差或交易价值。
