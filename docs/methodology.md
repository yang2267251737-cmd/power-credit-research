# 指标口径与研究限制

## 原始字段

所有原始金额带单位。`CNY` 为元，`CNY_1000` 为千元，`CNY_100M` 为亿元。计算统一为人民币千元。

`period_end` 为资产负债表时点；经营现金流与购建支出对应当年完整年度。初版不包含季度或半年数据，避免把不等长流量直接比较。

| 字段 | 定义 / 来源 |
|---|---|
| total_assets / total_liabilities | 合并资产负债表的资产总计 / 负债合计 |
| current_assets / current_liabilities | 合并资产负债表的流动资产 / 流动负债合计 |
| monetary_funds | 合并资产负债表的货币资金，不自动等同于可用于发行人偿债的现金 |
| restricted_monetary_funds | 财报附注披露的受限货币资金 |
| remittance_restricted_funds | 单独披露的境外汇回受限金额，不与受限货币资金自动相加 |
| operating_cash_flow | 合并现金流量表的经营活动现金流量净额 |
| cash_capex | 购建固定资产、无形资产和其他长期资产支付的现金；不包括全部投资支出 |
| interest_bearing_debt | 年报债券章节披露的合并口径有息债务，不等同于直接加总财报若干科目 |
| short_term_interest_bearing_debt | 同章节合并口径一年以内到期有息债务，包含一年；不等同于流动负债 |
| perpetual_equity | 权益列报永续债账面值；不自动计入披露的有息债务 |

## 计算公式

| 指标 | 公式 | 解读边界 |
|---|---|---|
| 资产负债率 | 总负债 / 总资产 | 永续债等权益分类会影响结果 |
| 流动比率 | 流动资产 / 流动负债 | 不能直接体现应收款质量 |
| 现金短债比 | 货币资金 / 一年内到期有息债务 | 未调整资金限制或集团内调拨约束 |
| 调整现金短债比（代理） | (货币资金 - 已披露受限货币资金) / 一年内到期有息债务 | 境外限制、可用性及重叠限制另行研究；不能称为完全可用现金短债比 |
| OCF / 有息债务 | 当年经营现金流 / 期末有息债务 | 流量对时点存量，不是偿债覆盖率 DSCR |
| 短债占比 | 一年内到期有息债务 / 有息债务 | 期末快照，未体现之后的偿还和新增融资 |
| 现金流代理 | OCF - 购建长期资产支付现金 | 不等同于严格定义的 FCFF / FCFE，未扣除全部投资、利息与分红 |
| 永续债重分类情景杠杆率 | (总负债 + 权益列报永续债) / 总资产 | 假设100%重分类的敏感性情景，不是评级机构调整值 |
| 现金流冲击情景 | OCF × 80% - 购建支出 × 110% | 假设场景，未预测债务服务或融资行为 |

零或负分母时比率留空，缺失原始字段不填零。经营现金流和现金流代理允许为负。

## 可比性与时间

当前选择 2025 年报告中的 2024 年比较数，有利于报表口径连续比较，但华电国际经过重述。不要把这些比较数当成 2024 年底投资者已知的数据。后续扩展时保留披露日期和重述版本，按研究用途选择“最新可比口径”或“历史当时可得口径”。

债务章节披露有息债务时，华能国际与华电国际以亿元保留两位小数，大唐国际以整亿元披露。单位转换不能提高原数据的实际精度。最终结论需要核对融资租赁、永续工具、应计利息等定义差异。

2024 年债务章节期初值是否与重述报表完全可比尚待核查，初版不使用其构造跨年债务比率。

## 尚未覆盖的信用判断

母公司偿债能力、资金下沉和分红回流、股东支持、可用授信、再融资渠道、煤价与电价、担保与或有负债、债券条款、个券流动性及利差。金融比率只能作为这些研究的入口。
