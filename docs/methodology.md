# 指标口径与研究限制

## 原始字段

所有原始金额带单位。`CNY` 为元，`CNY_1000` 为千元，`CNY_100M` 为亿元。计算统一为人民币千元。
下表的报表字段依据 `scope` 分别取合并或母公司数值；母公司指上市发行人自身，不能替换为控股集团。

`period_end` 为资产负债表时点；经营现金流与购建支出对应当年完整年度。初版不包含季度或半年数据，避免把不等长流量直接比较。

| 字段 | 定义 / 来源 |
|---|---|
| total_assets / total_liabilities | 合并资产负债表的资产总计 / 负债合计 |
| current_assets / current_liabilities | 合并资产负债表的流动资产 / 流动负债合计 |
| monetary_funds | 合并资产负债表的货币资金，不自动等同于可用于发行人偿债的现金 |
| restricted_monetary_funds | 财报附注披露的受限货币资金 |
| remittance_restricted_funds | 单独披露的境外汇回受限金额，不与受限货币资金自动相加 |
| operating_cash_flow | 合并现金流量表的经营活动现金流量净额 |
| cash_capex | 购建固定资产、无形资产和其他长期资产支付的现金；不包括全部投资支出 |
| interest_bearing_debt | 年报债券章节披露的合并口径有息债务，不等同于直接加总财报若干科目 |
| short_term_interest_bearing_debt | 同章节合并口径一年以内到期有息债务，包含一年；不等同于流动负债 |
| perpetual_equity | 权益列报永续债账面值；不自动计入披露的有息债务 |
| investment_income_cash | 取得投资收益收到的现金；包含不同投资来源，不直接等于子公司股利回流 |
| finance_company_deposits | 单独列示的财务公司存款；不自动归入受限或自由可用资金 |
| debt_disclosed_opening | 债券章节报告期初有息债务；仅作版本核查，不参与覆盖指标 |

表中“合并”字样指 `scope=consolidated`；`scope=parent` 使用同名母公司科目。母公司受限资金尚未录入，调整现金短债比留空。

## 计算公式

| 指标 | 公式 | 解读边界 |
|---|---|---|
| 资产负债率 | 总负债 / 总资产 | 永续债等权益分类会影响结果 |
| 流动比率 | 流动资产 / 流动负债 | 不能直接体现应收款质量 |
| 现金短债比 | 货币资金 / 一年内到期有息债务 | 未调整资金限制或集团内调拨约束 |
| 调整现金短债比（代理） | (货币资金 - 已披露受限货币资金) / 一年内到期有息债务 | 境外限制、可用性及重叠限制另行研究；不能称为完全可用现金短债比 |
| OCF / 有息债务 | 当年经营现金流 / 期末有息债务 | 流量对时点存量，不是偿债覆盖率 DSCR |
| 短债占比 | 一年内到期有息债务 / 有息债务 | 期末快照，未体现之后的偿还和新增融资 |
| 现金流代理 | OCF - 购建长期资产支付现金 | 不等同于严格定义的 FCFF / FCFE，未扣除全部投资、利息与分红 |
| 永续债重分类情景杠杆率 | (总负债 + 权益列报永续债) / 总资产 | 假设100%重分类的敏感性情景，不是评级机构调整值 |
| 现金流冲击情景 | OCF × 80% - 购建支出 × 110% | 假设场景，未预测债务服务或融资行为 |

零或负分母时比率留空，缺失原始字段不填零。经营现金流和现金流代理允许为负。
经营现金流为负时，“下降20%”按乘法反而可能缩小流出，故当前情景不适用，返回空值并标记 `negative_ocf_not_applicable`。未另行假设流出扩大。

## 可比性与时间

`report_vintage` 对应来源年报年度。2025版本含2025本期和2024比较数；2024版本含2024本期和2023比较数。事实和计算主键均包括版本与报表口径，不跨组拼接。华电国际2025年报的2024合并比较数已重述；大唐国际2024年报的2023合并比较数标为经重述。母公司2024比较数按原表列示，不能因合并报表重述就统一贴重述标签。

当前覆盖三个财务年度，但没有统一合并范围的三年连续序列。比较2023与2025前，需完成合并范围桥接。年度报告版本也不等于历史当时可得版本：2023比较数来自2025年公布的2024年报，不可直接用于2023年底回测。

债务章节披露有息债务时，华能国际与华电国际以亿元保留两位小数，大唐国际以整亿元披露。单位转换不能提高原数据的实际精度。最终结论需要核对融资租赁、永续工具、应计利息等定义差异。

2024年末债务类别只录入华能、华电2024年报明确披露的期限原表。2025年报的2024期初债务单独保存；即使华能两个版本总额相同，也不自动推断期限、计息或合并范围完全一致。大唐2024年报未找到同类期限表，本版本保留缺失。

## 原文矛盾与校验例外

`debt_breakdown.csv` 保留总额、短债、长债和空白。检查完整类别列之和、完整类别行的短长之和，以及明细合计与事实表的对应金额。舍入容差为0.03亿元；超过容差只有在 `evidence_issues.csv` 登记且来源、检查类型、分类、字段和实际差额精确一致时才放行，旧例外失效或其他异常均报错。

华能2025合并非银行贷款行：138.90 + 98.33 = 237.23，与行合计236.42差0.81亿元；短债分类135.36 + 774.43 + 138.90 = 1048.69，与列合计1047.88差0.81亿元。同一原文疑点产生两个检查例外，不计为两个独立财务事件。原值未更正，短债分母使用披露合计，待发行人更正或其他可靠材料确认。

`reconciliation.csv` 记录相同字段的旧版、新版和差额。有息债务对照比较旧报告年末与新报告期初，`comparison_type=year_end_vs_next_report_opening`；这种对照不等于已完成债务重述调节表。

## 页码

`pdf_page` 从1开始，是下载文件的物理页序；`report_page` 为报告印刷页码。两者在港交所文件中存在偏移，链接跳转使用 `pdf_page`。

## 尚未覆盖的信用判断

母公司现金来源已初步列示，但资金下沉、股利来源、资金调拨限制、股东支持、可用授信、再融资渠道、煤价与电价、担保与或有负债、债券条款、个券流动性及利差尚待深入核查。金融比率只能作为这些研究的入口。

## 收益确认、收现与复核状态

`investment_income_evidence.csv`以measurement_basis区分accounting_income与cash_flow。收益构成只与收益合计核对；现金总额只与主事实表的investment_income_cash核对，不强行令现金等于当期收益。cash_minus_accounting是两种口径的差额，bridge_status保持cash_bridge_pending；它不等于跨期收现或子公司现金分红。

`review_log.csv`记录用户明确反馈的字段、确认值、日期及文件哈希／页码映射。用户反馈金额为约数时，原表精确元值由AI交叉核对，在日志备注中区分。每个user_verified记录必须有对应日志；未反馈字段保持agent_verified。问题的review_status与status分别表示原文复核和问题解决，用户确认原表算术矛盾不改变unresolved。
